## Project: Litsycal

GNOME Shell extension (48-50, plain GJS ES modules, no build step): a
compact panel calendar ported from Itsycal, backed by Evolution Data
Server. Human-facing map: `llms.txt`. Contributor guide: `CONTRIBUTING.md`.

### Module map

- `extension.js` - entry point; enable()/disable() own the indicator only.
- `indicator.js` - panel button/badge/countdown; owns the calendar widget.
- `calendarWidget.js` - month grid, agenda, time-zone clocks, keyboard.
- `calendarManager.js` - all EDS access, iCal parse/build, event index.
- `eventDialog.js` - create/edit panel, delete confirm, go-to-date, quick-add panels.
- `eventInfoPopover.js` - read-only event details popover.
- `floatingPanel.js` - base floating modal panel; `searchPanel.js` and
  `settingsMenuPanel.js` - Ctrl+F search and the settings menu.
- `outlinePainter.js` - Cairo month outline/highlights.
- `helpers.js` - shared Shell-process helpers (dates, URLs, tz rows).
- `quickAddParser.js`, `timeInput.js` - pure, Shell-independent, unit-tested.
- `prefs.js` - Adwaita preferences (separate GTK process).

### Commands

```bash
npm ci              # install dev dependencies first (lint/check need node_modules)
npm run lint        # ESLint (GNOME Shell ruleset)
npm test            # gjs -m tests/test-quickadd-time.js
npm run pot         # regenerate po/*.pot after adding/changing translatable strings
./scripts/check.sh  # everything CI runs; must stay in sync with .github/workflows/ci.yml
glib-compile-schemas schemas/ --strict --dry-run   # after editing schemas/*.xml
./scripts/dev-session.sh        # nested devkit Shell (own D-Bus bus, own EDS)
```

### Constraints

- Shell-process files: St/Clutter/Meta, never Gtk/Gdk/Adw. `prefs.js`:
  the reverse. `helpers.js` is Shell-only; prefs must not import it.
- Optional typelibs (EDS, location) load lazily via `await import()`
  inside `try` - never a static top-level import.
- Signals: `connectObject()`/`disconnectObject(owner)`, never bare
  `connect()` (prefs exempt). Nothing at module scope; disable() removes
  sources, then signals, then resources, then `super.destroy()`.
- User-visible strings in `_()`/`ngettext()`; comments plain ASCII and
  only where they explain why. Tests only in `tests/`, only for the pure
  modules. Add user-facing changes to CHANGELOG `[Unreleased]`.
